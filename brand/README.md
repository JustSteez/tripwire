# Tripwire: brand kit

Everything here is generated by `build.mjs` with text outlined to paths, so the SVGs render the same everywhere. Rebuild after any change:

```bash
npm install && npm run build
```

## Files

| Asset | Use it for | Files |
|---|---|---|
| Mark | Primary logo, app icon, favicon source | `svg/mark.svg`, `png/mark-512.png`, `png/mark-1024.png` |
| Mark on paper | On dark backgrounds | `svg/mark-on-paper.svg`, `png/mark-on-paper.png` |
| Lockup | Headers, partner logos, decks | `lockup-on-paper`, `lockup-on-ink`, `lockup-transparent` (svg + png) |
| X profile picture | X / Telegram avatar (400×400, safe for circle crop) | `png/x-profile.png` |
| X header | X banner (1500×500, plus 3000×1000 retina); bottom-left kept clear for the avatar | `png/x-banner-1500.png`, `png/x-banner-3000.png` |
| Link preview | Open Graph / X card (1200×630) | `png/og-image.png` |
| Launch posts | 1600×900 images for the launch thread | `posts/post-1…4` (svg + png) |

Post copy is in [POSTS.md](POSTS.md).

## Colours

| Name | Hex | Role |
|---|---|---|
| Ink | `#16140F` | Text, the mark tile, footers |
| Paper | `#F2EDE3` | Backgrounds |
| Signal red | `#E0401F` | The spike, high-severity events (code swaps, admin moves, pauses) |
| Amber | `#C98A0C` | Owner changes, unpauses |
| Green | `#2E7A50` | Renounces, "live" dot |
| Muted | `#8A8274` | Timestamps, captions |
| Rule | `#D6CDBB` | Hairlines |

## Type

- **Archivo** at 68 width / 800 weight: headlines, always UPPERCASE.
- **Archivo** at 125 width / 900 weight, tracked +6%: the TRIPWIRE wordmark only.
- **Archivo** regular / semibold: body copy.
- **IBM Plex Mono**: addresses, timestamps, labels.

Static Archivo instances in `fonts/` are cut from the variable font with `fontTools.varLib.instancer`. Both fonts are under the SIL Open Font License (see `fonts/OFL-*.txt`).

## The mark

A taut wire on an ink tile, tripped into one sharp spike. The wire is paper; the spike is always signal red. On dark backgrounds, use the paper tile with an ink wire.
